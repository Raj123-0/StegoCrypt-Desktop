# Stegocrypt Desktop

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![CI](https://github.com/Raj123-0/StegoCrypt-Desktop/actions/workflows/ci.yml/badge.svg)](https://github.com/Raj123-0/StegoCrypt-Desktop/actions)


Secure Steganography Desktop App. Combines AES-128 Encryption (via Fernet) with LSB Image Steganography.

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/Raj123-0/StegoCrypt-Desktop.git
cd StegoCrypt-Desktop
python "StegoCrypt.py" --help
```

## Testing

```bash
pytest tests/
```
